# ZKP Learning Roadmap

> A curated roadmap to learn Zero-Knowledge Proofs — from math foundations to ZK auditing and job opportunities.

---

## 📝 Notes

Hey friends! This is a roadmap I've put together for learning ZKP, and I'd like to share a few notes before you dive in:

**Note 1:** This roadmap is based purely on my own experience. So if you've come across a resource that helped you and isn't listed here, feel free to message me and I'll add it.

**Note 2:** Everyone enters the ZK space with different goals and reasons for staying. That means not everything on this list will be useful or relevant to everyone.

**Note 3:** You don't need to go through every resource listed under each section. If you're interested and have the time, pick one to learn from and simply skim the rest. The idea is that different people learn in different ways, so having options lets you find the one that clicks for you. I've just done my best to include the highest-quality resources.

**Note 4:** Some of these resources are more reference-style — meant to be consulted occasionally rather than read cover to cover.

## 🧭 Suggested Learning Path

For someone starting from scratch, a logical order would be:

1. **Mathematical & Cryptographic Prerequisites** — build the foundation
2. **ZK Fundamentals & Advanced Concepts** — understand the theory
3. **A ZK Circuit Language** — pick one: Circom, Noir, or ZoKrates (get hands-on)
4. **Rust or C++** — depending on which ecosystem you're targeting
5. **Real-World ZK Projects** — see how it's applied
6. **ZK Auditing & Security** — specialize
7. **Job Opportunities** — enter the field
