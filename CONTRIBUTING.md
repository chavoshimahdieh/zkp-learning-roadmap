# Contributing to ZKP Learning Roadmap

Thanks for wanting to contribute! This roadmap is community-driven, and your suggestions make it better for everyone.

## What You Can Contribute

- **New resources** — books, courses, articles, videos, tutorials, or blog posts about ZK
- **Updated links** — if a link is broken or outdated
- **Better categorization** — if a resource belongs in a different section
- **Typos / fixes** — small corrections in the README
- **Job boards** — new places to find ZK-related roles

## How to Contribute

### Option 1: Open an Issue (easiest)

If you don't want to edit files yourself, just [open an issue](../../issues) with:

- The **resource name** and **link**
- A **short description** (1–2 sentences)
- Which **section** it belongs to (e.g., "ZK Fundamentals", "Circom", etc.)
- Why you think it's worth adding

### Option 2: Submit a Pull Request

- **Fork** this repository
- **Create a branch**: `git checkout -b add-resource-name`
- **Edit** `README.md` and add your resource in the appropriate section
- **Follow the existing format** (see below)
- **Commit** with a clear message: `Add: <resource name> to <section>`
- **Push** and open a **Pull Request**

## Formatting Guidelines

Please follow the existing style so the README stays consistent:

- Use a bullet point with an emoji matching the resource type:
  - 🧩 Puzzle / Exercise
  - 💼 Job board
- Format: `- 📘 **Title** — https://link.com`
- Keep descriptions short (one line max)
- Add the resource to the **most relevant section** in the Table of Contents

**Example:**

- 📘 **Zero-Knowledge Proofs: A Beginner's Guide** — https://example.com/zk-guide

## What We Avoid

- ❌ Promotional or affiliate links
- ❌ Paywalled content with no free alternative
- ❌ Low-quality / spammy resources
- ❌ Duplicate entries

---

## Review Process

- I'll review PRs and issues as quickly as possible (usually within a few days).
- Not every suggestion will be added — this list is curated, and I try to keep quality high.
- If your suggestion isn't added, don't be discouraged — feel free to suggest something else!
